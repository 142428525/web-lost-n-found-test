# DEMANDS.md
## 三个主要功能
- 失物列表：首页展示所有失物，按发布时间倒序。每条内容显示物品名称、丢失地点、丢失时间、联系方式（脱敏显示，如138****1234，于失物详情页点击“查看联系方式”后显示完整号码）。
- 搜索失物：搜索框为空时默认显示全部；用户输入关键词，可按物品名称/丢失地点匹配。
- 发布失物：用户填写物品名称（必填）、丢失地点（必填）、丢失时间（选填）、联系方式（必填），点击“发布”后持久化储存。

## 技术约束
- 单文件实现：`\index.html`。
- 使用原生HTML/CSS/JavaScript，不用框架、三方库和包管理器。
- 数据储存于浏览器localStorage，不用后端数据库。

## 数据结构
每条失物信息由以下字段组成：
- `id`：`Date.now()` + 随机数
- `title`：失物描述
- `location`：丢失地点
- `time`：丢失时间
- `contact`：联系方式
- `status`：失物状态枚举（默认“待认领”）
- `createdAt`：发布时间戳
- （可选）图片：一张，不超过500KiB，用Base64编码储存。

## UI
- 一种主色 + 扁平化设计
- 简洁实用风格：尽量减少页面元素数量，不搞花哨的背景、特效、动画。
- 响应式布局：适配不同屏幕尺寸的用户。
